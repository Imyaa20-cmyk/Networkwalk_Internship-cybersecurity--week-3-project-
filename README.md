## 1. Project Overview

This repository documents my Week 3 practical exercises as part of the Networkwalks Cybersecurity Internship.

The project focuses on password security assessment and understanding how password recovery techniques work against password-protected PDF documents.

I explored two different approaches to password recovery:

1. John the Ripper (JTR) and Johnny graphical interface.
2. Networkwalks online Hash Calculator and Password Cracker tools.

Both exercises used the authorised training PDF supplied for the internship.

The purpose was to understand password hash extraction, password recovery workflows, password complexity and the importance of strong authentication practices.

## 2. Project Objectives

- Understand the fundamentals of password cracking.
- Understand the difference between encryption and hashing.
- Extract password-related hash data from a protected PDF.
- Practise password recovery using John the Ripper.
- Explore the Johnny graphical interface.
- Use Networkwalks Hash Calculator and Password Cracker.
- Verify recovered passwords against the supplied training document.
- Understand why weak passwords create security risks.
- Learn defensive password security practices.
